# Industrial Attachment Management System (IAMS)

A full-stack platform built for Murang'a University of Technology to digitize 
industrial attachment (internship) logbooks and supervisor evaluations- 
replacing paper-based processes with role-based dashboards for students, 
university supervisors, company supervisors, and admins.

**Tech stack:** React · Node.js · Express · MySQL · JWT Authentication

**Features:**
- Digital logbook entries replacing manual paper records
- Automated evaluation scoring (20-mark and 80-mark scaled systems)
- Role-based dashboards for 4 distinct user types
- Form validation and structured duty-assumption workflows
